# 🛍️ ShopZone – E-Commerce Website

## 📌 About the Project

ShopZone is a modern e-commerce website developed to provide
users with a simple and convenient online shopping experience.

The website allows users to explore products, view prices,
manage their shopping cart, enter shipping details, and
complete the checkout process.

The project focuses on creating a clean, user-friendly
interface for online shopping.

## ✨ Features

- Attractive home page
- Featured products section
- Product listing page
- Product search and category filtering
- Product prices and ratings
- User login interface
- Add-to-cart functionality
- Update product quantities
- Remove products from the cart
- Checkout page
- Shipping address form
- Order summary
- Order confirmation page
- Easy navigation between pages

## 🖥️ Website Pages

### 1. Home Page
Displays the website banner and featured products.

### 2. Products Page
Displays available products with images, prices,
ratings, and shopping cart buttons.

### 3. Login Page
Provides a login interface for users.

### 4. Cart Page
Displays selected products, quantities, and subtotal.

### 5. Checkout Page
Allows users to enter shipping details and
review their order before placing it.

### 6. Order Success Page
Displays an order confirmation message.
